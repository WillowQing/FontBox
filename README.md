## 下载与打开

1. 打开上方下载页面，在 **Assets / 资源** 中选择 `ZiXia-1.7.0-Windows-x64.zip`。请勿下载 GitHub 自动生成的 Source code 压缩包，里面没有可运行程序。
2. 完整解压到本地文件夹，再打开其中的 **字匣.exe**，不要在压缩包内直接运行或单独移动 exe。
3. 首次启动自动扫描当前电脑已经安装的字体，等待扫描完成即可浏览；扫描不会复制或重新安装系统字体。

当前版本 **1.7.0 免费公测版**，Windows x64。当前下载包为便携版，无需安装 Node.js、注册账号或购买字体包。

## 可以做什么

- **真实字体预览**：自定义中英数字样字、字号和背景，网格或列表浏览。
- **收藏与分类**：亮金色收藏星星，快速勾选分类、拖拽归类、批量整理；取消收藏需二次点击确认。
- **字体类型与语言筛选**：衬线、无衬线、手写、书法、纯英文、汉字等组合筛选。
- **授权资料整理**：记录授权标签、来源、备注和许可证附件。待核实字体保留不确定状态。
- **字体对比与缺字提示**：并排比较候选字体，核对具体字重是否支持样字。
- **自动收录**：扫描已安装字体，也可以监听指定文件夹里的新字体。
- **PS / AI 换字**：卡片、详情与对比台可应用到当前目标文字；默认点击字体只浏览，不修改 Adobe 文档。
- **侧边吸附**：拖到屏幕边缘收起，悬停展开。关闭窗口可选择最小化或退出。
- **导入、导出与资料备份**：自行管理字体文件，备份收藏、分类与授权记录。

## Adobe 联动范围

- **Photoshop**：一个活动、可编辑文字图层的整层换字；实测 Photoshop 2026 / 27.1.0。
- **Illustrator**：选择一个独立文字对象，支持点文字和区域文字的整框换字；实测 Illustrator 2026 / 30.0.0。
- 支持指定字重和撤销；字号、颜色等格式保留。字宽变化可能造成重新换行或溢出。
- 暂不支持局部文字选区、多选、AI 串接文本框或已转曲文字。其他 Adobe 版本尚未全面验证。
- 所选字体必须已被目标软件识别，不会自动安装字体或替换成别的字体。

## 数据与隐私

字体路径、收藏、分类、备注等保存在 `%LOCALAPPDATA%\ZiXia`。字体与整理资料在本机处理，软件没有账号、云同步或自动上传功能。点击官方字体入口时会在浏览器打开相应网页。

分享包不含开发者的字体、收藏、分类、授权合同或资料库。更新前建议在软件内备份字体资料；备份 JSON 不包含字体文件及许可证附件。
